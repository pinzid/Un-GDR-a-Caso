# **App Name**: D&D Adventure Zone

## Core Features:

- Interactive Map: Display an interactive map where the DM can upload a base map image.
- Character Management: Allow users to manage their characters and move them on the map using drag and drop.
- Dynamic Lighting and Fog of War: Implement dynamic lighting and fog of war effects to simulate the exploration of the map. 
- Turn Tracking: Allows players to indicate their readiness, which enables an orderly progression through the player character list.

## Style Guidelines:

- Primary color: Dark, rich green (#346751) evoking a natural, earthy feel.
- Background color: Dark grey (#222222), very slightly tinted green.
- Accent color: Golden yellow (#FFC300) for interactive elements and highlights to catch the eye and give prominence to key details.
- Headline font: 'Playfair', a serif font, to bring a stylish, somewhat literary look.
- Body font: 'PT Sans', a sans-serif font to ensure readability.
- Use fantasy-themed icons (swords, potions, etc.) for actions and statuses.
- Map area should dominate the screen, with character controls and status information arranged around it.
- Smooth transitions for character movements and map explorations to enhance user engagement.
