# Un GDR a caso

Questa è un'applicazione Next.js per la gestione di una mappa da tavolo digitale per giochi di ruolo (GDR).

## Eseguire il Progetto in Locale

Per eseguire questo progetto sulla tua macchina locale, segui questi passaggi:

1.  **Apri il Terminale:** Naviga fino alla cartella principale del progetto.

2.  **Installa le Dipendenze:** Esegui il seguente comando per installare tutti i pacchetti necessari. Assicurati di avere [Node.js](https://nodejs.org/) installato.

    ```bash
    npm install
    ```

3.  **Avvia il Server di Sviluppo:** Una volta completata l'installazione, esegui questo comando per avviare l'applicazione in modalità di sviluppo.

    ```bash
    npm run dev
    ```

4.  **Apri nel Browser:** L'applicazione sarà disponibile nel tuo browser all'indirizzo [http://localhost:9002](http://localhost:9002).

A questo punto, vedrai la pagina iniziale e potrai iniziare a usare l'applicazione entrando come Master o come Giocatore.
